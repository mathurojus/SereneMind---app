## 📖 Introduction

**SereneMind** is a comprehensive mental health and stress management platform developed during the **Ozibook Hackathon 2025**. Our mission is to empower users to nurture their emotional well-being through innovative tools and personalized experiences. SereneMind combines mood tracking, mindfulness exercises, smart scheduling, and AI-powered insights to help you maintain a balanced and healthy lifestyle.

Whether you're dealing with daily stress, looking to improve your emotional awareness, or simply seeking tools to enhance your mental wellness, SereneMind is your trusted companion on the journey to better mental health.

## 📦 Installation Guide

### Prerequisites
Before you begin, ensure you have the following installed:
- Node.js (v14 or higher)
- npm or yarn
- MongoDB (local or cloud instance)
- Git

### Steps to Install Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/mathurojus/SereneMind---app.git
   cd SereneMind---app
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Configure environment variables**
   - Create a `.env` file in the root directory
   - Add the following variables:
     ```
     MONGODB_URI=your_mongodb_connection_string
     WHATSAPP_API_KEY=your_whatsapp_api_key
     SPOTIFY_API_KEY=your_spotify_api_key
     PORT=3000
     ```

4. **Start the development server**
   ```bash
   npm start
   # or
   yarn start
   ```

5. **Access the application**
   - Open your browser and navigate to `http://localhost:3000`

3. **Start Tracking**: Begin logging your daily moods and emotions

5. **Review Insights**: Check your dashboard for AI-powered insights and recommendations
6. **Stay Connected**: Enable notifications to receive wellness reminders
