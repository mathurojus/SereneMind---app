## Overview

**SereneMind** is a mental health and stress management platform designed to help individuals maintain emotional balance, develop mindful habits, and improve daily productivity.  
Developed during the **Ozibook Hackathon 2025**, this app integrates wellness tracking, AI-driven recommendations, and productivity tools into a single seamless experience.

---

## Features

### 📊 Mood Tracking & Emotional Insights  
- Log and visualize daily moods through an elegant, data-driven dashboard  
- Identify emotional trends over time  
- Get personalized suggestions and wellness insights powered by AI  

### 🧘 Guided Mindfulness & Breathing Techniques  
- Practice deep-breathing and mindfulness routines  
- Reduce stress and anxiety with guided steps and calming animations  

### 🗓️ Smart Daily Planner  
- Blend productivity with wellness habits  
- Schedule work, breaks, and relaxation sessions in one interface  

### 🎬 Mood-Based Media Recommendations  
- Curated playlists, podcasts, and movies to match your mood  
- Smart recommendations dynamically update based on your emotional state  

### 🎮 Mini Games for Relaxation  
- Fun, lighthearted games designed to ease tension and boost positivity  

### 💬 WhatsApp & Device Integration  
- Get gentle reminders, daily check-ins, and motivational nudges via WhatsApp  
- Sync with smartwatches and connected devices  

### 🌙 MoodLight UI Mode  
- Calming UI with light and dark theme options for visual comfort

## 🚀 Getting Started

Follow these instructions to set up and run **SereneMind** locally.

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/mathurojus/SereneMind---app.git
````

### 2️⃣ Navigate into the Project Directory

```bash
cd SereneMind---app
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Run the Development Server

```bash
npm run dev
```

Now, open your browser and visit **[http://localhost:3000](http://localhost:3000)** 🎉
